# Proyecto – Jade Barbershop

## Descripción
Aplicación de escritorio en Java para la gestión de citas de una barbería. Permite administrar clientes, citas, tipos de servicio, lista de espera y horario de atención. Incluye envío de notificaciones por correo electrónico y persistencia de datos en disco.

## Funcionalidades principales
- CRUD de clientes, citas y tipos de servicio.
- Calendario de citas y lista de espera.
- Envío de notificaciones de confirmación.
- Configuración de horario de atención.
- Interfaz gráfica con Java Swing.

## Tecnologías
- Lenguaje: Java
- Programación Orientada a Objetos
- Java Swing (interfaz gráfica)
- Persistencia en archivos
